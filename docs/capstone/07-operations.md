# Operations

Nothing is deployed; quarry runs where it is invoked, as a precompiled binary.

## Processes

| Process | Local command | Depends on |
| --- | --- | --- |
| `quarry` | installer: `curl -LsSf https://github.com/<owner>/quarry/releases/latest/download/quarry-installer.sh \| sh` (PowerShell variant on Windows), or `cargo binstall quarry`, or a downloaded release archive; developers: `cargo run -- …` | `git` on PATH; nothing else (SQLite is compiled in) |

No containers, no daemons, no scheduled jobs. The source-repo CI job (`mockup/05-ci-workflow.md`) is the user's workflow, not a quarry process.

## Configuration

| Variable / flag | Default | Consumed by | Meaning |
| --- | --- | --- | --- |
| `QUARRY_DOCS_REPO` | unset | `config::resolve` (clap `env`) | docs repo URL when no `.config` (S12) |
| `QUARRY_DOCS_DIR` | `docs/capstone` | `config::resolve` | docs folder in the source repo |
| `QUARRY_DEFAULT_BRANCH` | derived | `config::resolve` | the branch `update` imports from, when `origin/HEAD` does not say |
| `--json` | off | `Context`, `output` | machine output (S13) |
| `--verbose` | off | `gitcmd::Git::run` | echo each git command to stderr |
| `--force` | off | `commands::init`, `commands::update` | relink (S12) / import over a diverged stamp (S1) |

Nothing else is configurable; there is no config file beyond `.quarry/.config`.

## Infrastructure

None at runtime. CI for quarry itself: `.github/workflows/ci.yml` (PR and main: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test` on `ubuntu-latest`, `macos-latest`, `windows-latest`, stable toolchain) and `.github/workflows/release.yml` generated by `dist init` (`cargo-dist`): tag `v*` → build `x86_64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu`, `x86_64-unknown-linux-musl`, `aarch64-apple-darwin`, `x86_64-apple-darwin`, `x86_64-pc-windows-msvc` → GitHub Release with archives, shell and PowerShell installers, `cargo binstall` metadata, checksums. `dist-workspace.toml` holds the target list and installer choice. Semver; `quarry --version` prints the crate version.

## Developer workflow

| Task | Command |
| --- | --- |
| build | `cargo build` |

| format | `cargo fmt` |
| migrations | none; a `schema_version` bump rebuilds the index |
